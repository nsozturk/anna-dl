## Why anna-dl?

<CardGrid stagger>
  <Card title="Zero Paid API Keys" icon="star">
    Operate freely without requiring donation tokens, fast-download memberships, or external subscription keys.
  </Card>
  <Card title="Pure Python Core" icon="rocket">
    Lightweight and fast (under 150 KB). Starts instantly in milliseconds with Python requests and regex.
  </Card>
  <Card title="DDoS-Guard Evasion" icon="padlock">
    Automated stealth headless browser fallback resolving JavaScript challenges (`&check=1`) seamlessly when plain HTTP meets HTTP 403.
  </Card>
  <Card title="10-Candidate MD5 Recovery Loop" icon="setting">
    Sequentially tests up to 10 unique MD5 candidate hashes until a verified working download stream is found.
  </Card>
